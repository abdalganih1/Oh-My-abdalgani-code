# 🛰️ abdalgani gateway — Cloudflare Workers + D1

> هالملف للمدير (صاحب البوابة). دليل الطالب/المستخدم بـ [README الرئيسي](../README.md).

## 🗺️ نظرة عامة

بوابة ذكاء اصطناعي خاصة على **Cloudflare Workers** (بديل LiteLLM) بنظام توجيه مثل OpenRouter، مع لوحة تحكم للطلاب ولوحة مدير، وأداة تثبيت تربط أدوات البرمجة (OpenCode 2، Claude Code، Hermes، Codex…) بالبوابة بأمر واحد.

```
الطالب (OpenCode / Claude Code / Hermes / Codex / SDK)
        │  sk-abd-…
        ▼
api.abdalgani.com  ── Cloudflare Worker + D1
  • /v1/chat/completions  (OpenAI)
  • /v1/messages          (Anthropic — Claude Code)
  • /v1/responses         (OpenAI Responses — Codex)
  • التحقق من الاشتراك ← اختيار المسار ← مفتاح مزوّد (تدوير + احتياط) ← المحاسبة
        │
        ├── Z.AI Coding Plan   (OpenAI + Anthropic endpoints)
        ├── OpenRouter          (OpenAI + Anthropic endpoints، الكلفة الفعلية من usage.cost)
        ├── Anthropic           (Messages native، و OpenAI-compat)
        ├── OpenAI Platform     (Chat Completions؛ /v1/messages يُترجَم تلقائياً)
        ├── NVIDIA NIM          (Chat Completions — عدة مفاتيح مجانية بالتناوب)
        ├── OpenCode Zen        (pay-as-you-go، Chat + Anthropic)
        └── Nous Portal         (مزوّد Hermes الرسمي)

  ⏱ Cron كل 30 دقيقة: اكتشاف النماذج الجديدة ← نشر تلقائي "جديد" 7 أيام ← أرشفة الميت ← تنبيه
```


## 🎓 قواعد النظام (حسب الطلب)

- **لا تسجيل ذاتي، لا شراء، لا تجربة مجانية.** المدير ينشئ حساب الطالب ويعطيه مفتاح `sk-abd-…`.
- **الرصيد فقط عبر كوبونات** يولّدها المدير: إما **رصيد دولار** (مثلاً 10$) أو **توكنات** (مثلاً 10M)، وممكن تنحصر **بفئة نماذج** (Coding / Premium / Cheap…). بدون اشتراك فعّال يغطي النموذج ← `402`.
- **المحاسبة لكل نموذج** بأحد ثلاثة أوضاع: `request` سعر ثابت لكل طلب (كاش) · `token` جدول أسعارك لكل مليون توكن · `provider` الكلفة الفعلية اللي بيرجعها المزوّد (OpenRouter) — مع نسبة إضافية اختيارية.
- **الطالب يشوف** بلوحته: رصيده واشتراكاته، كل النماذج **الجديدة والقديمة** (المتاحة له والمقفولة)، سجل استهلاكه، ومفاتيحه.
- **تبديل النماذج بدون إعادة تثبيت:** كل الأدوات مضبوطة على أسماء ثابتة `abd-main` / `abd-fast` / `abd-think`، والطالب يغيّر لوين بتشير من لوحته فوراً.
- **الطالب دايماً بيعرف النموذج الحقيقي:** بلوحته (جدول "النماذج الحقيقية اللي عم تستخدمها" مع المزوّد اللي عم يخدم فعلياً)، وبكل رد (حقل `model` = النموذج الحقيقي + الترويسات `x-abdalgani-model` / `x-abdalgani-upstream` / `x-abdalgani-alias`)، وبسجل استهلاكه (`abd-main → glm-5.3`)، وبالطرفية `abdalgani-setup --status`. وأسماء النماذج داخل الأدوات نفسها مكتوب فيها الهدف (`abd-main → GLM-5.3`) وبتتحدث بـ `abdalgani-setup --sync`.
- **المدير** يضيف/يبدّل/يوقف **مفاتيح المزوّدين** من اللوحة (مشفّرة AES-GCM بالقاعدة)، مع عدة مفاتيح لكل مزوّد: توزيع بالأوزان + تبريد تلقائي للمفتاح اللي بيرجع 429/401 + انتقال للمسار الاحتياطي.

وزر **⬇️ تصدير CSV** لكل طلبات الفترة (بيفتح على Excel مع الأسماء العربية).

**لوحة الطالب ← "حسابي"**: رصيده بجملة وحدة ("استهلكت 38% · بيكفيك تقريباً 67 يوم · أقرب اشتراك بينتهي بعد 28 يوم")، رسم استهلاكه آخر 30 يوم، **"وين راح رصيدك؟"** حسب النموذج، متوسط كلفة الطلب، وشرح مبسّط لـ "شو يعني توكن وليش بعض الطلبات أغلى" مع نصائح للتوفير.


بوابة متوافقة مع OpenAI و Anthropic و Responses، مع اشتراكات بالكوبونات وتوجيه متعدد المزوّدين. بدون أي مكتبات تشغيل (JS خالص)؛ `wrangler` للنشر فقط.

## 🚀 النشر (مرة واحدة)

```bash
cd gateway
npm install
npx wrangler login
npx wrangler d1 create abdalgani-gateway        # انسخ database_id إلى wrangler.toml
npx wrangler secret put ADMIN_TOKEN             # كلمة سر لوحة المدير (طويلة وعشوائية)
npx wrangler secret put ENCRYPTION_KEY          # مفتاح تشفير مفاتيح المزوّدين — لا تغيّره بعدين
npx wrangler secret put NOTIFY_WEBHOOK          # اختياري: تنبيهات (Discord/Slack webhook، أو Telegram: https://api.telegram.org/bot<TOKEN>/sendMessage?chat_id=<ID>)
npm run db:migrate                              # كل الـ migrations (0001…0005): الجداول + المزوّدون (zai, openrouter, anthropic, openai, nvidia, opencode-zen) + فئات + نماذج GLM
npm run deploy
```

**الدومين:** `wrangler.toml` فيه `routes = [{ pattern = "api.abdalgani.com", custom_domain = true }]`. لازم دومين `abdalgani.com` يكون على Cloudflare، و**احذف سجل DNS القديم** لـ `api` (اللي كان يشير لسيرفر LiteLLM) قبل النشر. للتجربة أولاً: علّق سطر `routes` وانشر على `*.workers.dev`، جرّب، وبعدين حوّل.

> ⚠️ `ENCRYPTION_KEY` إذا تغيّر، المفاتيح المخزّنة ما عاد تنفك — رح تظهر بلوحة المدير بخطأ "cannot decrypt" وتحتاج تعيد إدخالها.

## 🧭 أول إعداد من لوحة المدير (`https://api.abdalgani.com/admin`)

1. **المزوّدون والمفاتيح:** أضف مفتاح Z.AI coding plan، ومفتاح OpenRouter، ومفاتيح NVIDIA (`build.nvidia.com` — كل حساب له حد طلبات، فأكثر من مفتاح = توزيع)، ولاحقاً Anthropic و OpenAI و OpenCode Zen. تقدر تضيف أكثر من مفتاح لنفس المزوّد (أوزان + احتياط). زر **اختبار** يتأكد إن المفتاح شغّال.
   - **أي مزوّد بأي رابط:** زر **+ مزوّد جديد** فيه قائمة جاهزة (DeepSeek، Moonshot/Kimi، MiniMax، Qwen، Gemini، xAI، Mistral، Groq، Cerebras، Together، Fireworks، DeepInfra، Hugging Face…) أو "مخصص" وبتحط أي رابط OpenAI-compatible و/أو Anthropic-compatible (لازم `https://`). بتقدر تضيف نفس المزوّد أكثر من مرة (حساب تاني). القائمة فيها بحث، وفلترة (مفعّل/موقوف/بلا مفاتيح/مؤرشف)، وكل مزوّد بينطوى ويفتح، ومفتاح تشغيل/إيقاف، وحذف نهائي.
2. **النماذج والتوجيه:** الافتراضي `abd-main`/`abd-think` ← `glm-5.3` و`abd-fast` ← `glm-5.3-flash` (z.ai أولاً، OpenRouter احتياط). زر **💲 أسعار OpenRouter** بيجيب أسعار OpenRouter الحالية لكل مليون توكن، بيطابقها مع نماذجك (من مسار OpenRouter أو من الاسم، ويدوياً إذا ما انطابقت)، وبيطبّقها بضغطة مع نسبة إضافية اختيارية. زر **📥 استعراض نماذج المزوّد** يجيب كتالوج المزوّد مع الأسعار والسياق، وزر "إضافة" يعبّي النموذج. كل نموذج له مسارات مرتّبة: الأول أساسي والباقي احتياط تلقائي (مثلاً `glm-5.3` ← zai، وإذا فشل ← OpenRouter `z-ai/glm-5.3`).
3. **الطلاب:** أنشئ طالب ← بيطلع مفتاح `sk-abd-…` مرة وحدة، أرسله له.
4. **الكوبونات:** ولّد كوبونات (دولار أو مليون توكن، لكل الفئات أو لفئة محددة، مدة الاشتراك، عدد الاستخدامات). أو امنح اشتراك مباشر من صفحة الطالب.
5. **الأسماء الثابتة:** `abd-main / abd-fast / abd-think` وين بتشير افتراضياً (الطالب يقدر يغيّرها لنفسه).

## 💳 منطق الفوترة

- العملة مخزنة بالـ micro-USD (`1$ = 1,000,000`) كأعداد صحيحة.
- لكل طلب يُختار اشتراك واحد بالترتيب: توكنات مخصصة للفئة ← توكنات عامة ← دولار مخصص ← دولار عام، والأقرب انتهاءً أولاً.
- اشتراك التوكنات ينقص بـ (input + output)، اشتراك الدولار ينقص بالكلفة المحسوبة.
- أوضاع التسعير: `request` (ثابت لكل طلب) · `token` (لكل 1M دخل/خرج/كاش) · `provider` (الكلفة الحقيقية من OpenRouter `usage.cost`، وإلا جدول التوكن) + `markup_pct`.
- **`auto` (تلقائي — الافتراضي لكل نموذج، يدوي أو مُكتشف):** ما في أسعار تعبّيها. ترتيب المصادر لكل مسار: سعر يدوي للمسار (إذا حطيت) ← سعر OpenRouter لنفس النموذج ← السعر المنشور بكتالوج المزوّد نفسه ← آخر سعر معروف (النموذج ما بيصير مجاني لأن البحث فشل). زر **حدّث الأسعار** بصفحة النماذج بيحدّث فوراً. ولنموذج تحته عدة نماذج (مثل `fast`): كل مسار بياخد سعر OpenRouter للنموذج اللي بيخدمه (مطابقة بالاسم: `glm-5.3-flash` ⇄ `z-ai/glm-5.3-flash`، `claude-sonnet-5-5` ⇄ `anthropic/claude-sonnet-5.5`)، والطلب بينحسب بسعر **المسار اللي ردّ فعلياً**. سعر النموذج الظاهر للطالب = أغلى مسار ("حتى …"). الأسعار بتتحدث مرة باليوم (مع الـ Cron)، ومع كل حفظ، ومن زر "حدّث الأسعار". مسار ما إله سعر على OpenRouter ← حطله "سعر يدوي" من المحرر (ما بيتكتب فوقه).
- الطلبات الفاشلة لا تُحتسب. البث (streaming) يُحاسب بعد انتهاء البث من أرقام `usage` الحقيقية.

## 🔀 التوجيه والاحتياط

- **نموذج واحد، عدة مزوّدين:** نفس النموذج من مزوّدين (مثلاً Claude Sonnet من Anthropic و Nous) = نموذج واحد بعدة مسارات. صفحة النماذج بتكشف المكرّر وبتعرض **ادمجهم** (أو زر **دمج**): المسارات بتنتقل، واختيارات الطلاب والسجل بيتحولوا للنموذج الباقي. وعند النشر من "التحديثات" اختار **مسار لنموذج موجود** بدل نموذج جديد.
- `abdalgani/<id>` و `abd/<id>` مقبولة (البادئة تُشال). الاسم يُحلّ: اسم الطالب المخصص ← الاسم الثابت العام ← معرّف النموذج.
- المفاتيح: ترتيب عشوائي موزون. 429 ← تبريد 60 ث، 401/403/402 ← ساعة، 5xx/شبكة ← 20 ث، ثم المفتاح التالي ثم المسار التالي. أخطاء 400 تُرجع للعميل فوراً بدون استهلاك مفاتيح أخرى.
- الترجمة: Claude Code (`/v1/messages`) على مزوّد بدون Anthropic endpoint (OpenAI) ← ترجمة كاملة مع الأدوات والبث. Codex (`/v1/responses`) ← يُترجم دائماً إلى Chat Completions (بما فيه custom tools مثل `apply_patch`).
- `reasoning_effort` يُحذف تلقائياً للنماذج غير المفعّل لها "يدعم التفكير".
- **توافق لكل مزوّد (`compat` JSON بلوحة المدير):** `max_tokens_field` (يحوّل max_tokens ⇄ max_completion_tokens)، `developer_role: false` (يحوّل رسائل developer إلى system)، `efforts` (المستويات المقبولة؛ الباقي يُقرّب لأقرب مستوى — Hermes يرسل `reasoning_effort` دائماً، و`ultra` ← `max`). مضبوطة مسبقاً لـ Z.AI و NVIDIA و OpenAI و OpenRouter و Anthropic.
- **شفافية النموذج الحقيقي:** كل رد يرجع `model` = المعرّف الحقيقي + ترويسات `x-abdalgani-model` و `x-abdalgani-upstream` (مزوّد/معرّف) و `x-abdalgani-alias`، والسجل يحفظ `requested_model` و `upstream_model`.
- كل الطلبات للمزوّدين تحمل `User-Agent: abdalgani-gateway/2.1` (OpenCode يطلب تعريف العميل).

## 🛡️ الأمان (تبويب "الأمان" بلوحة المدير)

| التهديد | الحماية |
|---|---|
| صرف أكثر من الرصيد / طلبات متوازية على نفس الرصيد | **حجز مسبق ذرّي**: قبل كل طلب تُحجز الكلفة التقديرية (`used += hold` فقط إذا بقي ضمن الرصيد)، وبعده تُستبدل بالكلفة الحقيقية أو تُرجع كاملة عند الفشل |
| تخمين المفاتيح / كلمة سر المدير / الكوبونات | عدّاد محاولات خاطئة لكل IP ← حظر تلقائي مؤقت (افتراضياً 10 خلال 10 د ← ساعة) + حدث + تنبيه |
| إغراق بالطلبات | حدود Cloudflare على الحافة: 240/د لكل IP و 90/د لكل مفتاح (`[[ratelimits]]`) + حد حجم الطلب |
| مفتاح مسروق أو مشارك | **ربط الأجهزة**: أداة التثبيت تولّد معرّفاً عشوائياً لكل جهاز (بدون معرّفات عتادية) وترسله بـ `X-Abd-Device`؛ وضع `enforce` = المفتاح يعمل فقط من N أجهزة مسجّلة، والزائد ينتظر موافقتك؛ حظر جهاز أو IP بضغطة |
| نماذج بسعر صفر | سقف **توكنات** يومي لكل طالب (سقف الدولار لا يحميها) + تنبيه أحمر بالنماذج غير المسعّرة |
| هجوم يفضي حساباتك عند المزوّدين | **ميزانية يومية كلية**: عند الوصول إليها تتوقف الخدمة حتى اليوم التالي |
| تسريب تفاصيل حسابات المزوّدين | أخطاء المزوّد لا تصل للطالب (تُحفظ بسجلك)، وتُنظّف أي مقاطع تشبه مفاتيح؛ مفاتيح المزوّدين مشفّرة AES-GCM |
| XSS / clickjacking على اللوحات | CSP صارم بدون سكربتات inline، `frame-ancestors 'none'`، `nosniff`، `no-referrer` (`web/public/_headers`) |

> معرّف الجهاز (أو حتى MAC) يمكن نسخه ممن يملك المفتاح وملفات الإعداد — لذلك الحماية الحقيقية هي الحجز المسبق + السقوف + الحدود، وربط الأجهزة طبقة إضافية تمنع المشاركة السهلة وتسمح بالحظر.

## 👤 الحسابات، الحدود، كشف الإساءة، السجل المباشر

- **حسابات الطلاب:** الطالب بيسجّل بإيميل وكلمة سر (`/api/auth/register`) ← بيعمل مفاتيح API لحاله ← بيفعّل **كود التفعيل** منك. التسجيل لحاله ما بيعطي أي رصيد. أوضاع التسجيل: مفتوح / بموافقتك / مغلق. حماية: حد حسابات لكل شبكة باليوم، قفل الحساب 15 د بعد 5 كلمات سر خاطئة، PBKDF2 لكلمات السر، جلسات بتوكن عشوائي (مخزّن كهاش فقط) وما بتقدر تستدعي النماذج. **Turnstile اختياري**: `wrangler secret put TURNSTILE_SECRET` + متغير `TURNSTILE_SITE_KEY`.
- **حدود الطالب:** سقف يومي إجباري يبدأ بـ $5 (قابل للتعديل من لوحة الطالب ضمن "أعلى سقف" اللي بتحدده، وما بينلغى) + سقف شهري اختياري.
- **كشف الإساءة** (Cron + "افحص الآن"): يوم ثقيل، قفزة مقابل معدل الطالب، مفتاح من شبكات كثيرة، شبكة عليها حسابات كثيرة، نسبة فشل عالية، نمط متكرر، تسجيلات بالجملة. تنبيه واحد لكل (قاعدة، طالب/شبكة، يوم) + webhook.
- **كاشف الحلقات (لحظي):** نفس آخر رسالة لنفس النموذج N مرة خلال نافذة قصيرة ← إيقاف مفاتيح الطالب دقائق + تنبيه عالي الخطورة؛ فك الإيقاف بضغطة.
- **السجل المباشر:** `GET /api/admin/live?after=<id>` — يجيب الجديد فقط (مسح بالمفتاح الأساسي، ≤200 صف). اللوحة: `setTimeout` متسلسل كل 5 ث بدون تداخل، ≤500 صف بالصفحة، توقف تلقائي عند إخفاء التبويب/الخمول 10 د، تباطؤ أسّي عند الأخطاء.

**ضد الحلقات اللي بتستهلك مواردنا:** محاولات المزوّدين محدودة (≤3 مفاتيح لكل مسار)، Cron محدود بالاستعلامات المجمّعة، التنبيهات مكررة-ممنوعة، الـ webhook ≤30 حدث بالمرة، السجل المباشر مقيّد كما فوق، وحدود Cloudflare (IP/مفتاح) فوق كل شي.

## 📊 التقارير والمال

- كل طلب يسجّل `cost` (ما خُصم من الطالب) و `upstream_cost` (ما دفعناه فعلاً): كلفة المزوّد المبلّغ عنها (OpenRouter) ← وإلا `model_routes.cost_in/cost_out` ← وإلا سعر النموذج بدون الهامش؛ وصفر للمزوّدين `billing = subscription` (رسمهم الشهري `monthly_fee` يُحسب نسبياً بالتقارير).
- `coupons.sale_price` / `subscriptions.sale_price` = المال الحقيقي اللي دفعه الطالب (افتراضياً = قيمة كوبون الدولار؛ كوبون التوكنات حدّد سعره).
- `expenses` لأي دفعات يدوية (شحن رصيد، خطط…).
- `GET /api/admin/reports?from&to&tz` — الإجماليات، السلسلة الزمنية، أعلى النماذج/الطلاب، خريطة الذروة، المزوّدون، المال شهرياً. `GET /api/admin/reports/export` — CSV. `GET /api/me/report` — تقرير الطالب (اتجاه، حسب النموذج، كم يكفيه رصيده).

## ⏱ دورة حياة النماذج (Cron كل 30 دقيقة — `[triggers]` بـ wrangler.toml)

1. **مزامنة الكتالوج:** لكل مزوّد عنده مفتاح: `GET /models` ومقارنة بآخر مرة (`provider_models`). أول مزامنة = خط أساس صامت. الجديد ← حدث + نشر تلقائي حسب `providers.auto`:
   `{"publish":true,"free_only":false,"group":"coding","pricing_mode":"request","price_request":0,"markup_pct":0,"match":"^glm-"}`
2. **الغائب:** نموذج اختفى من قائمة المزوّد ≥ `missing_hours` (6) ← مساره مؤرشف؛ يرجع لو رجع.
3. **الصحة:** كل محاولة تسجّل نجاح/فشل للمزوّد والمسار. فشل متواصل (أول فشل ← آخر فشل) ≥ `archive_after_hours` (6) بدون أي نجاح ← أرشفة المزوّد، أو المسار فقط إذا المزوّد نفسه نجح لنماذج تانية بنفس الفترة. (429 ليميت 5 ساعات ما بيوصل للعتبة.) أخطاء 400 (غلط العميل) ما بتنحسب.
4. **النماذج:** نموذج بلا أي مسار حي ← `archived`؛ يرجع لحاله لما يرجع مسار. شارة `new` تنتهي بعد `new_days` (7). الاسم الثابت اللي هدفه مؤرشف ← يتحول لـ `abd-main`.
5. **التنبيهات:** الأحداث الجديدة ← `NOTIFY_WEBHOOK`. وبلوحة المدير تبويب **التحديثات** (+ "افحص الآن"، نشر/تجاهل المعلّق، إعدادات العتبات).
6. **الاستعادة:** إضافة مفتاح أو نجاح "اختبار" لمزوّد مؤرشف ← يرجع فوراً؛ أو زر ♻️.
